## What can still reach a shader

The title heap is **not** synonymous with every table bound to a draw. `heap_buffer_pass` can materialize slots in bulk/on workers, including ones a particular shader never picks. Conversely, `draw.rs::tables` detects tables with declared CBVs and can snapshot their bytes into independent aligned scratch slots (`scratch_held` → `defer_constants` → `constant_at`). These draws need not read the null title slot. This is why neither lost draw count nor an indoor-lighting pass list can be recovered from the single reason counter.

## G15 and how to read the next capture

On Metal check both the 16-byte title placement and the translated GPU address, use the **exact** GPU address, encode the shadow CBV extent in 16-byte units with the existing 64 KiB cap, and reject an extent beyond `shadow.left(address)` rather than binding it. No change to scratch snapshots, root raw SRVs, shader lowering or Metal code. `VICTORY_CBV_ALIGN=256` and non-Metal retain the old host-only guard and size rounding. `VICTORY_MAC_DROP_STATS=1` gives five-second **deltas** for candidates with either residue nonzero. Sum `n` by `(title_mod,gpu_mod,accepted)`; `accepted` means the placement check, not a confirmed shader load. `title_mod=0 && gpu_mod!=0` isolates pure shadow shifts; nonzero and unequal residues show a title misalignment and a shift. The separate `descriptor.cbv:extent_outside_shadow` counter checks span safety.

`cbv bind delta` joins via the real destination slot, not a reusable CPU staging handle. `last_named_table` means the most recent **named CBV** at that same destination, title address and size: the PSO sequence and stage hashes plus a sample root parameter and title-heap index. This historical association includes named tables that are themselves snapshotted. `bind_context_only` names the binder when available; a sweep can touch unrelated slots and a worker can report `seq=0` (unknown). Dynamically selected slots have no proven consumer without GPU indexing evidence. Use the hashes to look up the corpus, never label a light/probe pass from a nearby timestamp.
